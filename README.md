# Muhammad Zubair Asif Portfolio

This portfolio website is built with TypeScript, Vite, and modern web technologies to showcase projects, skills, and contact information.

## Pages
- Home: `/`
- About, skills, and services: `/about`
- Project portfolio: `/projects`
- Contact: `/contact`

Vercel rewrites these page URLs to the Vite app entry point so direct visits and refreshes work.

## Deployment
- Live site: https://portfolio-ten-murex-13.vercel.app/
